\# Data Engineer - Smart Manufacturing IoT-Cloud Monitoring



\## Dataset

Dataset yang digunakan adalah dataset Smart Manufacturing IoT dengan jumlah 10.000 data.



\## EDA

EDA dilakukan untuk memahami karakteristik dataset, meliputi:

\- Pemeriksaan struktur data

\- Pemeriksaan missing value

\- Pemeriksaan data duplikat

\- Analisis data numerik dan kategorikal

\- Visualisasi distribusi data

\- Analisis korelasi antar variabel



\## Preprocessing

Tahapan preprocessing yang dilakukan:

\- Konversi timestamp

\- Feature engineering dari timestamp

\- Encoding data kategorikal

\- Menghapus kolom timestamp setelah fitur waktu dibuat
